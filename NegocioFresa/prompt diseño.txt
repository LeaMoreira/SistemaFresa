🧩 Adaptación de Patrones de Diseño (Enfoque Estructurado para Escritorio)
Dado que el paradigma es estructurado, debes adaptar los siguientes conceptos mediante módulos y funciones en Python:

Singleton: El módulo de persistencia debe asegurar una única conexión al archivo SQLite por cada transacción.

Factory: Funciones encargadas de "fabricar" o formatear las estructuras de datos que se mostrarán en las grillas (Treeview) de Tkinter.

Observer: Lógica donde la función de 'ventas' actualiza inmediatamente la interfaz gráfica y notifica al módulo de 'reportes' ante alertas de stock mínimo.

Strategy: Funciones intercambiables para calcular precios o descuentos según si se aplica o no una promoción de categoría.

Decorator: Uso de decoradores en Python para validar que el usuario esté logueado antes de permitirle ejecutar ciertas acciones o abrir ciertas ventanas en Tkinter.

Builder: Funciones constructoras que arman los reportes complejos uniendo varias consultas de SQLite paso a paso.
